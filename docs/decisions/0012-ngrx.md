# ADR-0012: State with NgRx / Estado con NgRx

- Status: Accepted
- Date: 2026-11-11

## Context
The PDF allows services or NgRx to manage state safely.

## Decision
NgRx with `auth`, `loans` and `users` slices, effects for HTTP calls and selectors for the views.

## Alternatives considered
- Services with Signals (faster to implement for a 2-hour test).

## Consequences
More boilerplate, but it shows seniority and keeps authentication state centralized.
