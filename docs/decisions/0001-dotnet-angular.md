# ADR-0001: Solve the test with .NET + Angular / Resolver la prueba en .NET + Angular

- Status: Accepted
- Date: 2026-11-11

## Context
The original PDF is Java/Spring Boot + Angular; it must be solved with a .NET backend.

## Decision
Angular frontend consuming an ASP.NET Core API.

## Alternatives considered
- Spring Boot as the backend.

## Consequences
The frontend depends on the OpenAPI contract of the .NET backend.
